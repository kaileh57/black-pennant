# Black Pennant

A naval combat vehicle builder. Design a ship cell by cell, let its officers run the systems you don't want to, and take on a fleet that outnumbers you.

Status: pre-alpha. The design is frozen in [DESIGN.md](DESIGN.md); Milestone 0 prototypes come next. There are no builds yet.

Platforms: macOS on Apple Silicon and Windows x86_64.

## Running unsigned builds

Releases are free and unsigned.

- macOS: on first launch, macOS blocks the app. Open System Settings, then Privacy & Security, and choose Open Anyway.
- Windows: SmartScreen shows a warning. Choose More info, then Run anyway. On clean Windows 11 installs, Smart App Control blocks unsigned apps entirely.
